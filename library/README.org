#+title: Historical artwork
#+subtitle: the era icons this pack does not draw
#+author: Josep Bigorra

Almost every icon in this pack is drawn from primitives, because a folder is a
folder and a film reel is a film reel.  Some applications are the exception.
Their old icons *are* the object: Chrome's glass orb, VLC's traffic cone,
Wilber holding a brush, the graphite Terminal window of OS X, Safari's compass
or iCal's tear-off calendar.  A drawing of those would be a drawing of a logo,
so the pack ships the era artwork itself instead of a drawing of it.  (The
theme does cut *colourways* of that artwork for the second and third program
of a kind - see =Colourways= below - but the files in this directory are the
artwork as published and are never edited.)

=make_app_icons.py= renders each file here at every size instead of calling a
drawing function; nothing is traced, filtered or restyled.  Two kinds of file
live here:

- the four *marks* below, freely licensed and fetched from Wikimedia Commons or
  a GPL icon set;
- the *OS X era ensemble* in =apps/= — the icons Leopard, Mountain Lion and
  Mavericks actually shipped, Apple's own included, catalogued in
  =artwork.json=;
- the *volumes* in =volumes/= — the drives, discs, cards and peripherals of the
  same era, catalogued in =volumes.json= and installed into the theme's devices
  context rather than its applications one, because a USB key plugged into a
  desktop is a volume, not a program;
- the *places* in =places/= — the one place icon that is an object rather than
  a folder, the wire-mesh wastebasket, empty and full, catalogued in
  =places.json=.

* The OS X era ensemble

Eighty applications people remember from Panther through Snow Leopard —
Safari, iCal, Address Book, iPhoto, iMovie and GarageBand; Pages, Keynote and
Aperture; QuickTime and DVD Player; the utilities (Disk Utility, Keychain
Access, System Preferences, Activity Monitor, Migration Assistant, Grab, the
AirPort, ColourSync, DigitalColor and VoiceOver tools); the day-to-day tools
(Calculator, Chess, Clock, Photo Booth, Printer, Stickies and X11); Office 2011

Dreamweaver, Flash and Fireworks); the one-off tools of the era (Sherlock, the
Classic environment, Front Row, Automator, Toast, Popcorn, Google Earth and
LimeWire); and a few third-party icons of the day.  Their artwork is the file
Apple (or the vendor) published, resampled, never redrawn.

The catalogue is =artwork.json=: one record per icon with the era it belongs to,
which pack it came from, the size it was published at, and who owns it.
=make_app_icons.py= reads it into =HISTORY=, so adding an icon means dropping a
PNG in =apps/= and a record in the JSON, never touching the drawing code.

* The wastebasket

The places context is folders, with one exception: the bin.  No desktop wants
a folder icon where the trash is, and the era drew that object unmistakably -
the wire-mesh basket on its ring, and the same basket with the day's paper

=user-trash-empty= as well as =user-trash-full=:

* Colourways

One catalogued picture is often asked for by several programs at once: four
video editors, four terminals, six file managers, eight small games.  Showing
four identical gold stars would be honest but useless, so the theme cuts
*colourways* of the catalogued artwork - =messages-alt= is the same speech
bubbles in the modern blue, =finder-alt= the same face in green, =terminal-red=
the pack's own terminal on red glass - and the mappings spread a family over
them.

The rules live in =ALTS= in =tools/make_theme_apps.py= and are two operations:
=shift= turns the artwork's own hues, keeping its shading and its white parts;
=tint= keeps its luminance and puts everything on one hue, which is what turns
graphite chrome red without turning the prompt pink with it.  The files here are
untouched by that: a colourway is generated at build time from the copy the
theme ships, so the catalogue stays the artwork as it was published.

* Licence of this directory

Nothing in =library/= is CC BY-SA 4.0 like the rest of the pack, and it cannot
be: the marks belong to their owners.  The four files at the top keep the
licences in their table (public domain for Chrome, GPL for the VLC cone,
Wilber and the Mac4Lin terminal).  The era ensemble in =apps/= is *not*
free artwork — Safari's compass is Apple's, Word's W is Microsoft's, BetterZip's
box is MacItBetter's — and is included as a reference set for a theme that
dresses a desktop as that era, the way a wallpaper pack ships a photograph it
did not take.  Redistributing the pack redistributes those marks; if that is a
problem for your use, delete =library/apps/= and remove the =apps= records from
=artwork.json=, and every one of those applications falls back to the pack's own
drawing.  The volumes in =volumes/= are the same: they are a theme pack's
reproduction of the drive and device artwork of that era, and deleting the
directory and the records in =volumes.json= returns every volume to the object
the pack drew for it.

The places in =places/= are the same trade: the wastebasket is a theme pack's
reproduction of the era's object, and deleting the directory and the records in
=places.json= puts the pack's own bin back (see =PLACES= in
=tools/make_theme_places.py=).

The pack's own artwork in =skeu-icons/=, =app-icons/=, =generated/= and =svg/=
is unaffected.

* Why not draw them

A drawn VLC cone is a cone; a drawn Wilber is a blob with eyes; a drawn Safari
compass is the pack's own browser globe, which it already has.  The point of
this directory is that the icon people remember from the era is the icon they
get.  Every other application in the pack is still a painted object — see
=Artwork policy= in the top-level README.
