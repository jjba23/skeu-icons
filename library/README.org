#+title: Historical artwork
#+subtitle: the era icons four applications are better off with
#+author: Josep Bigorra

Almost every icon in this pack is drawn from primitives, because a folder is a
folder and a film reel is a film reel.  Four applications are the exception.
Their old icons *are* the object: Chrome's glass orb, VLC's traffic cone,
Wilber holding a brush, the graphite Terminal window of OS X.  A drawing of
those would be a drawing of a logo, so the pack ships the era artwork itself and
re-colours nothing.

=make_app_icons.py= renders each file below at every size instead of calling a
drawing function; the table in =HISTORY= in that script is the only place they
are wired up.  Nothing here is traced, filtered or restyled: the files are the
upstream artwork, at the size upstream published them.

Apple's Finder face and Xcode hammer in the theme are original drawings, not
library files; so are the other eight hundred applications.

* Licence of this directory

The four files keep the licences in the table above; they are *not* CC BY-SA
4.0 like the rest of the pack.  Each one is credited to its author and source,
and the pack's own artwork in =skeu-icons/=, =app-icons/= and =svg/= is
unaffected.  If you redistribute the pack, the licences travel with these four
files.

* Why not draw them

A drawn VLC cone is a cone; a drawn Wilber is a blob with eyes.  The point of
this directory is that the icon people remember from the era is the icon they
get.  Every other application in the pack is still a painted object — see
=Artwork policy= in the top-level README.
