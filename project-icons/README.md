# Project icons — one skeuomorphic icon per project

47 projects, 42 distinct objects: no icon mask, no rounded-square grid, no flat gradient, no
monogram on a coloured plate. Each icon is one thing you could pick up — a metronome for
the CI orchestrator, a combination lock for the secrets tool, Lady Justice for the test
framework, a chrome-rimmed help orb for heks-toon, a conductor for the music encyclopaedia —
lit by one key light and finished with a two-layer cast shadow.

```
project-icons/
  index.json              name, slug, purpose, object per project
  contact-sheet.png       all 47 at 256 px
  <slug>/
    icon-16.png … icon-1024.png
```

The artwork is generated by [`tools/render_skeu.py`](../tools/render_skeu.py) (through
`tools/make_project_icons.py`) with the relief renderer in `tools/skeu/`: signed-distance
silhouettes, a height field per part, normals, one key light, studio reflections for
metal, enamel/glass/paper/leather/wood shaders, and contact shadows where parts meet.

## Notes

* Objects are picked for what the project *is*, not for its name alone: `araneola` gets a spider
  because it crawls, `byggsteg` a metronome because it keeps the beat for every stage, `guix` the GNU
  because it is a GNU system. Where two projects really are the same tool in two sizes
  (`guix` / `guix-jointhefreeworld`, `symbanta` / `symbanta-dashboard`, `veritas` / `veritas.el`)
  they share an object and differ in material and accent.
* Every accent is a single hue at 0.40–0.75 saturation over a neutral body, so the set reads as a
  calm grid of metal, glass and paper with colour only where it means something.
* At 16 px each icon is a silhouette plus one internal shape; the motif detail is dropped, never
  smeared.
